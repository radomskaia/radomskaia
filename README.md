## Hi there 👋, I'm Alena Radomskaia

Frontend developer working with Vue 3, Nuxt 3 and TypeScript.

Right now I am responsible for the frontend of a video streaming product in a team of four. I designed and released an in-house HLS/MP4 video player as a Vue + TypeScript library, which replaced the paid third-party player used across the platform, and I migrated the production application from Nuxt 2 to Nuxt 3 behind unit, end-to-end and visual regression tests.

Before that I worked with Angular and React as a frontend intern at Yandex.

- 💼 Frontend Developer, Dec 2025 — present
- 📍 Thailand, remote — available in the Moscow time zone (UTC+3)

## 💼 What I work on

My current work lives in private repositories. In short:

**Video player library** — a standalone Vue and TypeScript library: dual playback engine (hls.js for browsers without native HLS, native playback in Safari), 20 independent runtime modules on the Composition API, a public API that lets host teams change the UI without forking (custom buttons, overridable icons, a scoped slot for the whole control bar), Vitest unit tests, Vite library build, GitLab CI.

**Nuxt 3 migration** — pages and layouts, server state on the Nuxt payload, typed route authorisation, dependency stack replacement. Before touching the code I covered the app with Vitest and Playwright and wrote a visual regression CLI that compares screenshots with pixelmatch across a BrowserStack matrix.
